# The Café Table ☕

A modern, responsive web application for a campus café and cafeteria. **The Café Table** allows students and faculty to browse the food and beverage menu, search for favorite dishes, manage their order cart, and track order receipts.

---

## ✨ Features

- **Categorized Menu**: Browse through Indian, Chinese, Fast Food, Snacks, Beverages, and Desserts.
- **Instant Search**: Real-time search across dishes, categories, and ingredients.
- **Interactive Cart**: Slide-out cart drawer with live subtotal calculations, instant item addition, quantity adjustments, and removal.
- **Simple Checkout**: Easy order placement with student details, UPI Demo verification, and Cash at Counter options.
- **Order Tracking & Receipts**: View past order summaries and itemized receipts saved locally in your browser.
- **Responsive & Elegant Design**: Clean, warm editorial aesthetic optimized for both mobile and desktop screens, featuring smooth animations and ambient effects.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic and accessible page structure.
- **CSS3**: Responsive layouts, custom properties, typography, and smooth transitions.
- **JavaScript (ES6+)**: Dynamic menu filtering, cart operations, local storage persistence, and interactive animations.

## 🚀 How to Run Locally

You do not need to install any heavy packages or backend servers to run this project.

### Option 1: Direct Browser Launch (Easiest)
1. Download or clone this repository.
2. Locate the `index.html` file inside the `the_cafe_table` folder.
3. Double-click `index.html` to open it in your favorite web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using VS Code Live Server
1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Using Python Local Server
If you have Python installed, open your terminal inside the project directory and run:
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
